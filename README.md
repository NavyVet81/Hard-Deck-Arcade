## Upload to GitHub Pages
1. Extract this archive.
2. Upload `index.html`, `README.md`, and the `games/` folder into a public GitHub repository.
3. Enable GitHub Pages under **Settings > Pages** (Branch: `main`, Folder: `/ (root)`).
